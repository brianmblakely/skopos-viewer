# Skopos Viewer - agent contract

## Skopos: work in flight (read this first)

Before starting work, read the Skopos increment store's `LATEST.md` - it is
the digest of current work across all agents, active work on top. Store
location: `SKOPOS_ROOT` env var if set, else `C:\Users\brian\skopos` (the
flat sibling of this repo). Full records live in `increments/`; the machine
index is `index.json`.

If the local clone is missing, the store is
`https://github.com/brianmblakely/skopos` (private; requires `gh`/auth).
Either way, proceed with your task - note that work-in-flight visibility is
off, but never stall or refuse because the store is unreachable.

Writing increments is governed by the store's own contract: see `AGENTS.md`
in the Skopos repo. Do not copy its write rules here.
